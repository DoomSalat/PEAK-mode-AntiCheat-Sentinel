# Peak Sentinel

Античит для PEAK (BepInEx 5). Определяет, **кто** сделал подозрительное действие, по отправителю сетевого сообщения — его ставит сервер Photon, подделать нельзя. Блокирует то, что можно заблокировать, и честно пишет, где защита работает только для тебя. Описание для страницы Thunderstore — [tools/thunderstore/README.md](tools/thunderstore/README.md).

## Что умеет

- **Ловит выдачу предметов**: себе и другим игрокам через встроенную команду «спавн в руки» (так работают спавнеры и читы), подбор от чужого имени, подмену чужого инвентаря, создание предмета, которого нет в инвентаре создателя.
- **Блокирует у хоста** незаконную выдачу: предмет просто не создаётся. Ванильные выдачи (паспорт в аэропорту, стартовый предмет режима Grapple) проходят. Свои спавны хоста можно разрешить.
- **Защищает хост**: если другой игрок сам делает себя хостом (так умеют только читы, запретить это сервер Photon не даёт), Sentinel сразу забирает хост обратно и пишет вора в лог; по галочке — ещё и кикает его (вкладка Other).
- **Защищает тебя и не у хоста**: если кто-то через хоста заспавнил предмет тебе в руки (ты его не подбирал и не просил), предмет не берётся в руку и убирается из инвентаря. Отключается галочкой во вкладке Items. Кто это сделал, клиенту не видно — видно только хосту.
- **Может игнорировать ванильные пинки** (вкладка Other, по умолчанию выключено): пинок другого игрока не роняет и не толкает тебя. После неё можно включить защиту всех, когда ты хост (тоже выключено по умолчанию): если пинки в забеге выключены, а кто-то пинается (это чит), пнутого сразу поднимают, а пинающий попадает в лог. Третьей галочкой — то же, когда ты клиент; галочки включаются только по порядку (по умолчанию выключено; другие античиты могут счесть это подозрительным).
- **Ловит вред чужой командой**: убийство, обморок, зомби/окаменение, телепорт и сильный рывок другого игрока — с ником того, кто это сделал.
- **Ловит события, которые вправе запускать только хост** (как PEAKER): конец игры, вертолёт, туман, костёр, мосты, извержение, бобы, верёвки, крюки, пчёлы, торнадо, Bing Bong, чужой банан и чужой призрак.
- **Детект полёта (прототип)**: игрок висит или поднимается в воздухе, а гравитация на него не действует. Свои проверки высоты и скорости, данным игрока о себе не доверяет. Также ловит слишком быструю горизонтальную скорость (быстрее бега дольше секунды) на любой высоте. Пороги настраиваются, цифры пишутся в лог.
- **Детект бесконечной стамины (прототип)**: игрок бежит или лезет, а его стамина, которую сообщает его клиент, не уменьшается. Только запись в лог (оранжевое подозрение) — заблокировать нельзя, стамина считается у самого игрока. Пороги в `[Stamina]`, цифры — строки STAMINA в PeakSentinel.log.
- **Эффекты без источника**: защита (молоко, амулет, гриб, золотой Bing Bong) или бесконечная стамина, а игрок ничего не съел и золотого Bing Bong в руке нет — подозрение на чит. Только запись в лог; название съеденного пишется строками EFFECT в PeakSentinel.log.
- **Ловит воскрешение без источника** (само-рес): честно воскрешают хост (статуя, Пустота), сам игрок сразу после захода в забег и игрок с чучелом скаута или Книгой костей в руке — остальное записывается как чит.
- **Метки Cherry и Atlas** (как в PEAKER): эти читы сами помечают своих пользователей, Sentinel это видит.
- **Окно менеджера (F6, клавишу можно сменить кнопкой в шапке окна)** в стиле ItemSpawnerPremium (Canvas + TextMeshPro, бежевые карточки, шрифт игры): вкладки Log (всё), Items (блокатор спавна предметов), Cheats (общие читы — у каждой проверки своя галочка блокировки, у меток Cherry/Atlas — авто-кик для хоста) и Players — у каждого игрока видно, что с ним не так, есть Kick (выкинуть из текущего лобби) и Ban (навсегда: пока ты хост, забаненный кикается при каждом входе в любое твоё лобби; список с Unban — на отдельной вкладке Bans, хранится в `BepInEx/config/PeakSentinel.bans.txt`) — оба только для хоста — и профиль со всеми находками по этому игроку.
- **Метки в меню Esc**: у аватарки игрока в списке игроков — оранжевый «?», если он вёл себя подозрительно, и пульсирующий красный «!», если на него есть запись о чите или блоке («!» важнее «?»).
- **Кнопка Fix в логе**: у находок, последствия которых можно отменить, — убил (воскресить на месте), обморок (поднять), телепорт или рывок (вернуть на место), потушил костёр (зажечь), сдвинул туман (вернуть). Работает и не у хоста (с подтверждением «Not host!»). У себя в логе появляется зелёная строка «fix: …»; другие Sentinel-клиенты честно увидят твоё вмешательство. Вертолёт, конец игры, мосты, зомби — не чинятся.
- **Лента подключений**: подозрительное и заблокированное видно прямо в игре.
- **Отладочный лог** `BepInEx/PeakSentinel.log`.

Подробнее — [index.md](index.md).

## Сборка

Нужны .NET SDK и PEAK с BepInEx 5. Путь к игре по умолчанию — `G:\SteamLibrary\steamapps\common\PEAK`, другой передаётся параметром:

```bash
dotnet build src/PeakSentinel -c Release -p:GameDirectory="D:\Steam\steamapps\common\PEAK"
```

Сборка кладёт `PeakSentinel.dll` в профиль Thunderstore Mod Manager `Default`: `BepInEx/plugins/PeakSentinel`. Другой путь — параметр `-p:ProfilePlugins=...`.

## Ограничения

- Каждый клиент сам решает, что выполнять. Команды вреда (убийство, телепорт, события хоста) идут жертве напрямую, мимо хоста: полностью защищён только тот, у кого стоит Sentinel. Хост блокирует для всех только то, что идёт через него, — выдачу и подбор предметов, — и может кикать и банить.
- Полёт, скорость, стамина и эффекты без источника — эвристика: может ошибаться, и в логе это помечено.
- Хост-читер не ловится; отобранный хост Sentinel забирает обратно, но окно в долю секунды остаётся.
- Каким именно модом сделан спавн, не определить: спавнеры не сообщают о себе по сети.
- Сервер Photon мод не меняет: серверную защиту для всех могли бы сделать только разработчики игры.
