# Peak Sentinel

Прототип античита для PEAK (BepInEx 5). Определяет, **кто** сделал подозрительное действие с предметами, по отправителю сетевого сообщения — его ставит сервер Photon, подделать нельзя. Хост может блокировать незаконную выдачу предметов.

## Что умеет

- **Ловит выдачу предметов**: себе и другим игрокам через встроенную команду «спавн в руки» (так работают спавнеры и читы), подбор от чужого имени, подмену чужого инвентаря, создание предмета, которого нет в инвентаре создателя.
- **Блокирует у хоста** незаконную выдачу: предмет просто не создаётся. Ванильные выдачи (паспорт в аэропорту, стартовый предмет режима Grapple) проходят. Свои спавны хоста можно разрешить.
- **Окно менеджера (F6)**: история находок с прокруткой и переключатели защиты.
- **Лента подключений**: подозрительное и заблокированное видно прямо в игре.
- **Отладочный лог** `BepInEx/PeakSentinel.log`.

Подробнее — [index.md](index.md).

## Сборка

Нужны .NET SDK и PEAK с BepInEx 5. Путь к игре по умолчанию — `G:\SteamLibrary\steamapps\common\PEAK`, другой передаётся параметром:

```bash
dotnet build src/PeakSentinel -c Release -p:GameDirectory="D:\Steam\steamapps\common\PEAK"
```

Сборка кладёт `PeakSentinel.dll` в профиль Thunderstore Mod Manager `Default`: `BepInEx/plugins/PeakSentinel`. Другой путь — параметр `-p:ProfilePlugins=...`.

## Ограничения

- Блокировка и большая часть проверок работают только у хоста: запросы выдачи предметов идут хосту.
- Хост-читер не ловится.
- Каким именно модом сделан спавн, не определить: спавнеры не сообщают о себе по сети.
